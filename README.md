## Краткое описание работы

В ходе лабораторной работы был создан минимальный веб-сервер на ASP.NET Core. Изучены основы маршрутизации, middleware, возврат JSON-данных и работа с параметрами маршрутов. Реализовано мини-API с несколькими эндпоинтами: главная страница, информация о студенте, калькулятор и обработка 404 ошибок.

### Что изучили:
- Создание веб-сервера с помощью `WebApplication.CreateBuilder()`
- Настройку маршрутов с параметрами (`/hello/{name}`, `/sum/{a}/{b}`)
- Возврат JSON-данных из маршрутов
- Работу middleware для логирования и добавления заголовков
- Автоматическую сериализацию C# объектов в JSON (PascalCase → camelCase)
- Разницу между `dotnet run` и `dotnet watch run`

## Список реализованных маршрутов

| Маршрут | Метод | Описание |
| --- | --- | --- |
| `/` | GET | Приветственное сообщение с временем на сервере |
| `/about` | GET | Информация о сервере |
| `/time` | GET | Текущее время на сервере |
| `/hello/{name}` | GET | Приветствие пользователя по имени |
| `/sum/{a}/{b}` | GET | Сумма двух чисел |
| `/student` | GET | Информация о студенте (JSON) |
| `/product/{id}` | GET | Информация о товаре по ID (JSON) |

## Главные выводы

1. **ASP.NET Core — мощный и гибкий фреймворк** — он позволяет создавать веб-серверы с минимальным количеством кода (Minimal API), при этом сохраняя высокую производительность и поддержку современных стандартов.

2. **Порядок middleware критически важен** — middleware выполняются в том порядке, в котором они зарегистрированы в `Program.cs`. Маршруты (`MapGet` и т.д.) должны регистрироваться после всех middleware, иначе они не будут обработаны.

3. **Автоматическая сериализация JSON упрощает разработку API** — достаточно вернуть C# объект (анонимный или из класса), и ASP.NET Core сам преобразует его в JSON, автоматически применяя camelCase для имён полей.

## Итоговая таблица

| Характеристика | ASP.NET Core |
| --- | --- |
| Создание сервера | `WebApplication.CreateBuilder()` |
| Запуск | `app.Run()` |
| Маршрут GET | `app.MapGet("/", fn)` |
| Параметр маршрута | `{name}` → `(string name)` |
| Возврат JSON | `return new {...}` / `Results.Ok(...)` |
| Middleware | `app.Use(async (ctx, next) => ...)` |
| Логирование | Встроенное + `Console.WriteLine` |
| Статус ответа | `Results.NotFound(...)` |
| Тип данных | Строгие (C# record, class) |
